# Mini Site Builder

A miniature drag-and-drop website builder built on top of [GrapesJS](https://grapesjs.com/), created with the help of AI coding tools to explore how low-code and no-code builders work under the hood.

> **Live demo:** https://onthatile77.github.io/custombuilder/nova-builder_10.html

## About the project

Website builders like Webflow and Wix hide a lot of engineering behind a simple interface. I built this project to understand that machinery: how a visual editor models a page, how components and styles are managed, and how the result becomes real HTML and CSS.

I used AI tools to speed up development and directed the build myself, reviewing and adjusting the generated code along the way.
